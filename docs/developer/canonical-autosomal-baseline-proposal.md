# Autosomal quantitative baseline proposal

Phase 0.9.32 adds a bounded quantitative execution after successful structural validation of the approved 1000 Genomes Phase 3 chromosome 22 source. The execution creates a scientific-review proposal; it does not approve a production baseline or authorize a release.

## Fixed analysis contract

The proposal runner derives biallelic SNPs from `22:20000000-21000000` into a temporary work directory. It then runs the package pipeline with the approved panel, sample and variant missingness thresholds of 0.20, MAF 0.05, LD pruning at r2 0.20, seed 42, ten requested principal components, and four compute threads. Only PCA is selected for this bounded execution.

Six observations are retained:

- derived interval variant count;
- retained sample count;
- QC-passing variant count;
- LD-pruned variant count;
- PC1 variance proportion;
- PC2 variance proportion.

The four counts use exact proposal comparators. The variance proportions use a relative tolerance of `1e-6` to allow supported numerical-library variation. These settings and values remain proposals until scientific review explicitly accepts or revises them.

#### PCA variance-proportion caveat (unresolved, not yet approved or rejected)

`pca_pc1_variance_proportion` and `pca_pc2_variance_proportion` are computed as `eig$values / sum(eig$values)` in `R/ordination.R` (`run_pca()`), where `eig$values` comes from `normalize_pca_eigenvalues()` after it discards SNPRelate's trailing `NaN` eigenvalue slots (see `R/zz_pca_eigenvalue_suffix.R` and `tests/testthat/test-pca-trailing-eigenvalues.R`). Because `SNPRelate::snpgdsPCA()` is called with `eigen.cnt = requested_components` (10 here), only the top 10 eigenvalues are ever computed; the denominator is the sum of *those 10 values only*, not the total genetic variance across the full eigenspectrum (rank-bounded by the 350 LD-pruned SNPs). This was verified empirically: the 10 proportions in `13_PCA_variance.tsv` sum to exactly `1.000000000000000`.

Consequently, "PC1 variance proportion = 0.2655" means PC1 accounts for 26.55% of variance *among the ten requested/computed components*, not 26.55% of total genetic variance in the dataset. This is consistent, tested, deliberate behavior applied package-wide (not a defect specific to this proposal), but it is a materially different scientific claim than an unqualified "percent of variance," and any caption, manuscript text, or approved-baseline record built from these two metrics should state the qualified definition explicitly rather than an unqualified "percent of variance explained." This caveat is recorded for scientific review; the two PCA metrics remain in `proposed` status pending an explicit reviewer decision on whether the existing definition is acceptable as-is or requires a documentation/metric-definition change before promotion.
