# popgenVCF 0.10.0 development

- Fixed `run_admixture_cv()` silently running non-independent "replicates": it set an `ADMIXTURE_SEED` environment variable that the ADMIXTURE binary does not read (confirmed empirically -- `strings` on the installed 1.3.0 binary shows it documents a `--seed=X` command-line flag, not an environment variable; repeated runs and runs with different `ADMIXTURE_SEED` values produced byte-identical Q matrices and log-likelihoods). `admixture_command_arguments()` now takes an explicit `seed` parameter and passes `--seed=X` on the command line, matching how `--cv=` is already passed; different seeds now produce genuinely different Q matrices and CV errors, as multi-replicate stability evidence requires. Found while proving out a real-data three-backend ancestry validation run for release issue #24: ADMIXTURE reported perfect (`stability = 1.0`) replicate agreement at every K from 2 to 10, which turned out to be an artifact of five identical runs rather than genuine convergence robustness.
- Added `test-pipeline.R`, the first end-to-end test of `run_pipeline()` itself (previously exercised only through mocks or source-text pattern matches): a full run against the real validation fixture is checked against its documented tables, RDS, and manifest artifacts, and a second run without a metadata file is checked against the module-skip warning path. This surfaced and fixed a real bug: `write_manifest()` unconditionally called `normalizePath()`/`hash_file()` on `cfg$input$metadata`, crashing `run_pipeline()` at its final step whenever no metadata file was supplied -- a configuration this package explicitly supports elsewhere (`metadata_from_samples()`). The manifest's `metadata`/`metadata_sha256` fields are now `NA` when metadata is absent instead of the pipeline failing outright.
- Removed `DESCRIPTION`'s redundant `Author:` field (R derives it automatically from `Authors@R`, and the two had drifted, producing an `R CMD check` NOTE); updated `scripts/validate_release_metadata.R`'s identity check to match.
- Added `test-chromosome.R`, closing the last gap in chromosome-specific analysis coverage: `run_chromosome_analyses()`'s per-chromosome grouping is cross-checked against direct `run_fst()`/`run_pca()` calls on the same real fixture data, its SNP-count and LD-pruned-count thresholds are exercised independently, and `write_chromosome_results()`'s file output, empty-input, and chromosome-name-sanitization paths are verified.
